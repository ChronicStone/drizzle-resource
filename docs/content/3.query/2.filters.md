title: Filters

`filters` is a list of nodes combined with `AND`. A node is either a **condition** on one field or a **group** that combines other nodes with `and` or `or`.

## Condition

```ts twoslash
import type { QueryFilterCondition } from "drizzle-resource";

// ---cut-start---
const condition: QueryFilterCondition =
  // ---cut-end---
  {
    type: "condition",
    key: "status", // a field path
    operator: "is",
    value: "active",
  };
```

## Group

```ts twoslash
import type { QueryFilterGroup } from "drizzle-resource";

// ---cut-start---
const group: QueryFilterGroup =
  // ---cut-end---
  {
    type: "group",
    combinator: "and", // "and" | "or"
    children: [
      // conditions or other groups
    ],
  };
```

## Operators

| Operator   | SQL               | Value                                                     |
| ---------- | ----------------- | --------------------------------------------------------- |
| `is`       | `= value`         | one value                                                 |
| `isNot`    | `<> value`        | one value                                                 |
| `isAnyOf`  | `IN (values)`     | an array                                                  |
| `contains` | `ILIKE '%value%'` | text, case-insensitive                                    |
| `gt`       | `> value`         | one value                                                 |
| `gte`      | `>= value`        | one value                                                 |
| `lt`       | `< value`         | one value                                                 |
| `lte`      | `<= value`        | one value                                                 |
| `between`  | `BETWEEN a AND b` | `{ from, to }`, both included; either end may be left out |
| `before`   | `< value`         | same as `lt`, for dates                                   |
| `after`    | `> value`         | same as `gt`, for dates                                   |

## A group inside the list

Orders that are not cancelled, and either worth at least 1,000 or from a customer whose name contains "acme":

```ts twoslash
// @noErrors
import type { QueryRequest } from "drizzle-resource";

const request: Pick<QueryRequest, "filters"> = {
  // ---cut---
  filters: [
    {
      type: "condition",
      key: "status",
      operator: "isNot",
      value: "cancelled",
    },
    {
      type: "group",
      combinator: "or",
      children: [
        {
          type: "condition",
          key: "totalAmount",
          operator: "gte",
          value: 1000,
        },
        {
          type: "condition",
          key: "customer.name",
          operator: "contains",
          value: "acme",
        },
      ],
    },
  ],
};
```

## Filters on relation paths

Any path reachable through the resource's relations can be filtered on:

```ts twoslash
import type { QueryFilterCondition } from "drizzle-resource";

// ---cut-start---
const nestedFieldFilter: QueryFilterCondition =
  // ---cut-end---
  {
    type: "condition",
    key: "orderLines.product.category",
    operator: "is",
    value: "electronics",
  };
```

A path through a to-many relation compiles to an `EXISTS` subquery, so an order matches when at least one of its lines matches, and it is returned once.

## Building filters on the server

In the scope and in custom stages, use the typed filter builder instead of writing objects by hand:

```ts twoslash
import { createQueryFilterBuilder } from "drizzle-resource";
import type { MyFieldPaths } from "./twoslash-support";

const f = createQueryFilterBuilder<MyFieldPaths>();

// The same filter as the group example above
f.and([
  f.isNot("status", "cancelled"),
  f.or([f.gte("totalAmount", 1000), f.contains("customer.name", "acme")]),
]);
```

It has one method per operator, plus `f.and` and `f.or`. See the [filter builder reference](/reference/filter-builder).

## Client filters and the scope

The effective condition is always `(scope) AND (client filters)`. An empty `filters` list leaves only the scope. See [Scope](/resource/scope).
