## Requirements

- Drizzle ORM `>=1.0.0-rc.4` with relational queries enabled, so `db.query.<table>.findMany(...)` exists.
- Your schema and relations, defined with `defineRelations` or `defineRelationsPart`.
- TypeScript with `strict: true` for the most precise field-path types.

## Install

::code-group

```bash [bun]
bun add drizzle-resource
```

```bash [pnpm]
pnpm add drizzle-resource
```

```bash [npm]
npm install drizzle-resource
```

::

Request and response validators are separate entry points of the same package: `drizzle-resource/zod`, `drizzle-resource/valibot` and `drizzle-resource/vine`. Install the validator you already use; see [Validation](/serve/validation).

## What the engine needs

```ts twoslash
import { db, relations, schema } from "./twoslash-support";
// ---cut---
import { createQueryEngine } from "drizzle-resource";

const engine = createQueryEngine({
  db, // your Drizzle database instance
  schema, // your tables, keyed by name
  relations, // your Drizzle relations
});
```

| Option      | Used for                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------ |
| `db`        | Running the queries. Row loading uses Drizzle's relational query API.                            |
| `schema`    | Deriving field paths and their types, compiling filters and sorting, reading unique constraints. |
| `relations` | Following relation paths such as `customer.name` and building joins.                             |

The package ships its own types; there is no `@types` package to install.
