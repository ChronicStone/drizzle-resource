---
title: Resource Methods
description: The five public methods on a defined resource — query, findById, queryIds, queryRows, queryFacets.
---

Every resource created with `engine.defineResource(...)` exposes five public methods.

## `resource.query(options)`

The full pipeline. Runs ids selection, row hydration, and optional facet resolution in one call.

```ts twoslash
// @noErrors
import { ordersResource } from "./twoslash-support";

const result = await ordersResource.query({
  context: { orgId: "acme" },
  request: {
    pagination: { mode: "offset", pageIndex: 1, pageSize: 25 },
    sorting: [{ key: "createdAt", dir: "desc" }],
    search: { value: "", fields: [] },
    filters: [],
    facets: [{ key: "status", mode: "exclude-self", limit: 10 }],
  },
});

// result: { rows: TRow[]; pageInfo: QueryPageInfo; facets?: QueryFacetResult[] }
```

**Returns:** `{ rows, pageInfo, facets? }`

- `rows` — the current page of hydrated rows, typed from the query hydration default or `load` override
- `pageInfo` — mode-specific pagination metadata, including `rowCount` when an exact count was requested
- `facets` — present only when `request.facets` is non-empty

## `resource.findById(options)`

Resolves one scoped row by its root `id`, using the `findById` hydration default and the same transaction override as `query`.

```ts twoslash
import { ordersResource } from "./twoslash-support";

const order = await ordersResource.findById({
  id: "order_123",
  context: { orgId: "acme" },
});

// order: hydrated order row | null
```

**Returns:** `TRow | null`

Use this for detail and mutation lookups. Scope remains structural, while pagination, sorting, search, and facet plumbing stay inside the resource.

## Hydration overrides

`query`, `findById`, and `queryRows` accept the same trusted `load` option. A named profile or inline relation subset replaces the operation default, and the returned row type follows that selection.

```ts twoslash
import { ordersResource, request } from "./twoslash-support";

const detailPage = await ordersResource.query({
  request,
  context: { orgId: "acme" },
  load: "detail",
});

const customerOnly = await ordersResource.findById({
  id: "order_123",
  context: { orgId: "acme" },
  load: { customer: true },
});
```

`queryIds` and `queryFacets` do not hydrate rows, so they do not accept `load`.

## `resource.queryIds(options)`

Runs only the ids stage and returns page ids with the same mode-specific pagination metadata.

```ts twoslash
import { ordersResource, request } from "./twoslash-support";

const { ids, pageInfo } = await ordersResource.queryIds({
  context: { orgId: "acme" },
  request,
});
```

**Returns:** `{ ids: TId[], pageInfo: QueryPageInfo }`

Use this when you want to:

- Cache page ids separately from row data
- Pass ids to a different service for hydration
- Batch id selection across multiple resources before hydrating

## `resource.queryRows(options)`

Hydrates a set of pre-ordered ids without running id selection again.

```ts twoslash
import { ids, ordersResource, request } from "./twoslash-support";

const rows = await ordersResource.queryRows({
  context: { orgId: "acme" },
  request,
  ids, // ordered ids from a previous queryIds call
});
```

**Returns:** `{ rows: TRow[] }`

The rows are returned in the same order as the input `ids` array. `queryRows` does not run a count query.

## `resource.queryFacets(options)`

Resolves facets independently from the page query.

```ts twoslash
import { ordersResource, request } from "./twoslash-support";

const { facets } = await ordersResource.queryFacets({
  context: { orgId: "acme" },
  request,
  facets: [{ key: "status", mode: "exclude-self", limit: 10 }],
});
```

**Returns:** `{ facets: QueryFacetResult[] }`

Use this when the facet sidebar loads separately from the main table — for example, on initial page load before the user enters a search.

## Return types

```ts twoslash
import type {
  QueryFacetResult,
  QueryFacetsResponse,
  QueryIdsResponse,
  QueryResponse,
} from "drizzle-resource";

type QueryResponseExample<TRow> = QueryResponse<TRow>;
type QueryIdsResponseExample<TId> = QueryIdsResponse<TId>;
type QueryFacetsResponseExample = QueryFacetsResponse;
type QueryFacetResultExample = QueryFacetResult;
```
