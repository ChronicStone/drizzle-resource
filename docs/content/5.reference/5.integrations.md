title: Integrations
description: Validator integration entry points shipped with drizzle-resource — the Zod and Valibot subpath exports.
---

`drizzle-resource` is published as a single npm package, with validator integrations exposed as dedicated subpath exports:

- `drizzle-resource/zod`
- `drizzle-resource/valibot`

These are the stable import paths for validator-specific tooling around the query contract. Installing `drizzle-resource` gives you both — no extra package to add.

## `drizzle-resource/zod`

```ts twoslash
import { queryZodIntegration } from "drizzle-resource/zod";

console.log(queryZodIntegration.package);
```

Exposes the Zod integration config:

- `queryZodIntegration` — the integration marker, `{ package: "zod" }`
- `QueryZodIntegrationConfig` — its type

## `drizzle-resource/valibot`

```ts twoslash
import { queryValibotIntegration } from "drizzle-resource/valibot";

console.log(queryValibotIntegration.package);
```

Exposes the Valibot integration config:

- `queryValibotIntegration` — the integration marker, `{ package: "valibot" }`
- `QueryValibotIntegrationConfig` — its type

## Current surface

The integration entry points currently expose these typed configuration markers only — validator-specific request parsing helpers are not bundled yet. The subpaths exist so that adopting them later is a non-breaking import away.

If you need to validate the wire format today, the request shape is documented in [Request Shape](/query-contract/request-shape) and typed via [`QueryRequest`](/reference/types), so you can derive a schema in the validator of your choice.
