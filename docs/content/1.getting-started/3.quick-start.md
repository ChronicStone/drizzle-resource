Three steps: bind an engine to your database, declare a resource, then query it.

## 1. Create the engine

The engine binds to one Drizzle connection and carries the type of your request context. Create it once and share it across every resource:

```ts twoslash [engine.ts]
import { createQueryEngine } from "drizzle-resource";

import { db } from "./db";
import { relations } from "./relations";
import { schema } from "./schema";

export const engine = createQueryEngine({ db, schema, relations }).withContext<{
  isAdmin?: boolean;
  orgId: string;
  userId?: string;
}>();
```

`withContext` is what makes `ctx` typed inside scope functions. Skip it and `ctx` is an untyped record.

## 2. Define the resource

Pick the root table, declare which relations to load, and set the field policy:

```ts twoslash [orders.resource.ts]
import { engine } from "./engine";
// ---cut-before---
export const ordersResource = engine.defineResource("orders", {
  relations: {
    customer: true,
    orderLines: { with: { product: true } },
  },
  query: {
    // Merged into every request before any client filter
    scope: (f, ctx) => f.is("customer.orgId", ctx.orgId),
    search: {
      allowed: ["reference", "customer.name", "orderLines.product.name"],
      defaults: ["reference", "customer.name"],
    },
    sort: { defaults: [{ key: "createdAt", dir: "desc" }] },
    facets: { allowed: ["status", "customer.name"] },
    defaults: { pagination: { pageSize: 25 } },
  },
});
```

Declaring `relations` does two jobs — it hydrates those relations onto each row, and it registers their columns as filterable field paths such as `customer.name`.

## 3. Run a query

Pass the caller's `context` separately from the client's `request`. The context never travels in the request body:

```ts twoslash
import { ordersResource } from "./orders.resource";
// ---cut-before---
const result = await ordersResource.query({
  context: { orgId: "acme" },
  request: {
    pagination: { mode: "offset", pageIndex: 1, pageSize: 25 },
    sorting: [{ key: "createdAt", dir: "desc" }],
    search: { value: "laptop", fields: [] },
    filters: [
      {
        type: "condition",
        key: "status",
        operator: "isAnyOf",
        value: ["pending", "processing"],
      },
    ],
    facets: [{ key: "status", mode: "exclude-self", limit: 10 }],
  },
});
```

`search.fields: []` falls back to the resource's `search.defaults`, so a client does not have to know which columns are searchable.

## 4. Read the result

A response carries the rows, the page metadata, and any requested facets:

```ts twoslash
import { ordersResource } from "./orders.resource";

const result = await ordersResource.query({
  context: { orgId: "acme" },
  request: {
    pagination: { mode: "offset", pageIndex: 1, pageSize: 25 },
    sorting: [],
    search: { value: "", fields: [] },
    filters: [],
  },
});
// ---cut-before---
result.rows;
//     ^?
```

Rows are fully typed from the schema and the declared relations — `result.rows[0].customer.name` and `result.rows[0].orderLines[0].product.sku` both resolve.

`pageInfo` is a discriminated union on `mode`, so narrow before reading mode-specific fields:

```ts twoslash
import { ordersResource } from "./orders.resource";

const result = await ordersResource.query({
  context: { orgId: "acme" },
  request: {
    pagination: { mode: "offset", pageIndex: 1, pageSize: 25 },
    sorting: [],
    search: { value: "", fields: [] },
    filters: [],
  },
});
// ---cut-before---
if (result.pageInfo.mode === "offset") {
  result.pageInfo.pageIndex;
  result.pageInfo.hasNextPage;
}

// `rowCount` is null unless the request asked for an exact count
if (result.pageInfo.count === "exact") {
  const total: number = result.pageInfo.rowCount;
}
```

Offset requests default to `count: "exact"`, so `rowCount` is a number unless you opt out. Cursor requests default to `count: "none"` — see [Pagination](/query-contract/pagination).

## The four query methods

| Method          | Use when                                                 |
| --------------- | -------------------------------------------------------- |
| `query()`       | Full pipeline — ids, rows, and optional facets           |
| `queryIds()`    | Page ids and page metadata only, for caching or batching |
| `queryRows()`   | Hydrate a known id list without re-selecting             |
| `queryFacets()` | Resolve facet buckets independently from the page        |
